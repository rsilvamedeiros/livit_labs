# Architecture Decision Records

ADRs registram decisões técnicas ou de produto difíceis de reverter. Cada registro deve explicar contexto, decisão, consequências e alternativas consideradas.

## Convenção

```text
NNNN-titulo-curto.md
```

Status permitidos: `Proposto`, `Aceito`, `Substituído` ou `Rejeitado`.
